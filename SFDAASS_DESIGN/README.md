# Smart Fire Detection, Alerting and Automated Suppression System

The Smart Fire Detection, Alerting and Automated Suppression System is a full-stack IoT solution designed to detect fire incidents in real time and support rapid emergency response. It integrates ESP32-based sensors with a web-based dashboard to monitor environments, visualize incidents on a map, and provide timely alerts. The system enhances safety by enabling early detection and efficient management of fire-related events.

The application is built using React and Vite for the frontend, Node.js and Express for the backend, and PostgreSQL (Neon) for the database, with Drizzle ORM for data management. It supports features such as real-time monitoring, geofencing, incident logging, and report generation. This project demonstrates the integration of IoT, cloud computing, and modern web technologies to deliver a scalable and intelligent fire safety solution.
