 
Smart Fire Detection, Alerting and Automated Suppression System – Web Dashboard UI/UX Prototype

---

 

Design a **modern, high-fidelity web dashboard UI prototype** for an IoT-based safety system called:

**“Smart Fire Detection, Alerting and Automated Suppression System”**

The interface language must be **English**.

The design should follow a **clean, professional, and safety-critical aesthetic**, using:

* Color palette:

  * Red (alerts / fire)
  * Blue (system info)
  * Green (safe/normal)
  * Dark gray / white (background)
* Style: Modern SaaS dashboard (similar to industrial monitoring systems)
* Typography: Clear, readable (e.g., Inter, Roboto)
* Use cards, charts, maps, and status indicators

---

## 🧩 Layout Structure

Create a **responsive web app layout** with:

* Left sidebar navigation
* Top header (system status + notifications + user profile)
* Main content area (dynamic pages)

---

## 📌 Pages to Design

---

### 1️⃣ Dashboard Page (Main Screen)

Design a real-time monitoring dashboard with:

* 🔥 Live Fire Alerts Panel (highlighted in red)
* 📊 Sensor Data Charts (temperature, smoke levels)
* 🌍 Interactive Map (show GPS location + geofence boundary)
* 💧 Sprinkler Status Indicator (ON/OFF)
* ⚡ System Health Status Cards
* 🚨 Alert Severity Indicators (Low / Medium / High)

Use cards and real-time UI elements.

---

### 2️⃣ Device Monitoring Page

Design a device management interface:

* Table or card layout showing:

  * Device ID
  * GPS Coordinates
  * Geofence Status (Inside/Outside)
  * Sensor Values
  * Last Seen Timestamp
  * Device Health (Online/Offline)
* Include filters and search
* Include status badges (color-coded)

---

### 3️⃣ Fire Incident History Page

Design a historical analytics page:

* Incident list (table or timeline)
* Each incident expandable to show:

  * Map location
  * Sensor readings
  * Response timeline
  * Sprinkler activation
* Include:

  * “Export PDF” button
  * “Export CSV” button

---

### 4️⃣ Geofence Management Page

Design an interactive map-based interface:

* Map with drawing tools
* Options:

  * Draw polygon geofence
  * Set radius-based geofence
* Editable boundary controls
* Save / update buttons

---

### 5️⃣ About Page

Design an informative page with sections:

* 📖 Project Overview
* ⚙️ Technologies Used (hardware + software)
* 🚀 System Capabilities (use icons)

Use a clean, structured layout with icons and illustrations.

---

### 6️⃣ Developer Portfolio Page

Design a team showcase page:

* Developer cards with:

  * Profile photo
  * Name
  * Role (IoT Engineer, Backend Dev, etc.)
  * Short bio
  * Skills tags
  * GitHub button
  * LinkedIn button

Use grid layout with modern cards.

---

### 7️⃣ Contact Page

Design a contact interface:

* Contact form:

  * Name
  * Email
  * Message
  * Submit button
* Side panel with:

  * Email address
  * GitHub link
  * LinkedIn links
* Add success notification UI

---

## 📊 Additional UI Elements

Include reusable components:

* Alert notification popups
* Status badges (Safe / Warning / Danger)
* Charts (line, bar)
* Map UI (Leaflet-style)
* Buttons (primary, secondary, danger)
* Cards and modals

---

## ✨ Interaction Requirements

Prototype should include:

* Page navigation (clickable sidebar)
* Hover states on buttons/cards
* Alert popups animation
* Modal for incident details
* Map interaction placeholders

---

## 🎯 Design Goal

Create a **professional, real-world IoT safety dashboard prototype** suitable for:

* Final year project presentation
* Portfolio showcase
* System demonstration

Focus on **clarity, usability, and real-time monitoring experience**.
